if, else if, 중첩 if와 매달린 else, switch와 break

선택문(選擇文 · 골라서 실행하는 문장)은 조건(條件 · 어떤 일이 이루어지기 위해 갖춰야 할 상태)에 따라 실행할 코드를 고르는 문법. 앞에서 배운 관계, 논리 연산자가 여기서 본격적으로 쓰인다.

SECTION 01

if

조건이 참(0이 아닌 값)일 때만 중괄호 안을 실행한다.

C
#include <stdio.h>

int main(void)
{
    int score = 85;

    if (score >= 60)
    {
        printf("합격\n");
    }
    return 0;
}
SECTION 02

if ~ else

참일 때와 거짓일 때를 나눈다.

C
int n = 7;

if (n % 2 == 0)
    printf("짝수\n");
else
    printf("홀수\n");
SECTION 03

else if

조건이 여러 개일 때는 위에서부터 차례로 검사하다가, 처음으로 참인 곳 하나만 실행하고 나머지는 건너뛴다.

C
int score = 85;

if (score >= 90)
    printf("A\n");
else if (score >= 80)
    printf("B\n");
else if (score >= 70)
    printf("C\n");
else
    printf("F\n");

위에서부터 검사하기 때문에 조건 순서가 중요하다. 만약 score >= 60을 맨 위에 두면 85점도 거기서 걸려버린다. 범위가 큰 조건이 앞에 오면 뒤의 조건은 실행될 일이 없어진다.

SECTION 04

중첩 if

중첩(重疊 · 거듭 겹침). if 안에 또 if를 넣을 수 있다.

C
int age = 20;
int hasTicket = 1;

if (age >= 19)
{
    if (hasTicket)
        printf("입장 가능\n");
    else
        printf("표가 필요합니다\n");
}

이 정도는 &&로 한 줄에 쓸 수도 있다(age >= 19 && hasTicket). 중첩이 깊어지면 읽기 힘들어지니까, 논리 연산자로 합칠 수 있으면 합치는 쪽이 깔끔하다.

else는 가장 가까운 if에 붙는다 (매달린 else)

중첩 if에서 else가 어느 if의 짝인지는 들여쓰기가 아니라 가장 가까운 if로 결정된다.

C
int a = 1, b = 5;

if (a > 3)
    if (b > 3)
        printf("둘 다 큼\n");
else
    printf("a가 작음\n");   // 들여쓰기와 달리 안쪽 if(b > 3)의 else

들여쓰기만 보면 바깥 if의 else 같지만, 컴파일러는 if (b > 3)의 else로 읽는다. 그래서 a=1일 때는 바깥 조건이 거짓이라 else까지 가지도 못하고 아무것도 출력되지 않는다. "a가 작음"이 찍힐 거라 기대했다면 틀린 것. 원하는 짝으로 붙이려면 중괄호로 묶어준다.

C
if (a > 3)
{
    if (b > 3)
        printf("둘 다 큼\n");
}
else
    printf("a가 작음\n");

사실 else if도 else 안에 if가 들어간 중첩 구조다. 한 줄로 이어 쓰는 것뿐이다.

SECTION 05

if에서 자주 하는 실수

중괄호를 생략하면 바로 다음 한 문장만 if에 속한다.

C
int n = 3;

if (n > 5)
    printf("크다\n");
    printf("이 줄은 항상 실행됨\n");   // if와 상관없이 실행

들여쓰기는 if 안에 있는 것처럼 보이지만 컴파일러는 들여쓰기를 보지 않는다. 문장이 둘 이상이면 항상 중괄호를 쓰자. 한 줄이어도 쓰는 걸 습관으로 들이는 게 안전하다.

그리고 조건식 뒤에 ;를 붙이면 안 된다. if (n > 5);라고 쓰면 아무것도 안 하는 빈 문장이 if의 내용이 되어버리고, 아래 줄은 항상 실행된다.

== 대신 =를 쓰는 실수도 여기서 많이 나온다.

SECTION 06

switch

값 하나가 여러 경우 중 어디에 해당하는지 고를 때 쓴다.

C
int menu = 2;

switch (menu)
{
    case 1:
        printf("커피\n");
        break;
    case 2:
        printf("녹차\n");
        break;
    case 3:
        printf("주스\n");
        break;
    default:
        printf("없는 메뉴\n");
        break;
}

break를 빼먹으면 그 아래 case까지 쭉 이어서 실행된다. 이걸 일부러 이용하는 경우도 있지만, 대부분은 실수라서 case마다 break를 쓰는 걸 기본으로 생각하면 된다.

C
int month = 4;

switch (month)
{
    case 12:
    case 1:
    case 2:
        printf("겨울\n");
        break;
    case 3:
    case 4:
    case 5:
        printf("봄\n");
        break;
    default:
        printf("기타\n");
        break;
}

break가 없는 걸 일부러 써서 여러 case를 하나로 묶은 예다. 4월이면 case 4부터 시작해서 break를 만날 때까지 내려가서 "봄"이 나온다.

default는 어떤 case에도 안 맞을 때 실행되는 곳이다. 보통 맨 아래에 두지만 위치는 어디든 상관없다. 다만 맨 아래가 아니라면 break를 꼭 써야 아래 case로 안 흘러간다.

switch는 정수나 문자 값에만 쓸 수 있다. 실수나 문자열은 안 되고, score >= 90 같은 범위 비교도 안 된다. 범위는 if ~ else if로, 딱 떨어지는 값은 switch로 나누면 된다.

switch를 if로 바꿔보기

switch는 if ~ else if로 바꿀 수 있다. break는 "나머지 case는 건너뛴다"는 뜻이라 else가 하는 일과 같다.

C
int menu = 2;

if (menu == 1)
    printf("커피\n");
else if (menu == 2)
    printf("녹차\n");
else if (menu == 3)
    printf("주스\n");
else
    printf("없는 메뉴\n");

반대로 범위 조건이 있는 건 switch로 바꿀 수 없다.

SECTION 07

예제: 윤년 판별

4로 나누어떨어지고 100으로 나누어떨어지지 않거나, 400으로 나누어떨어지면 윤년.

C
#include <stdio.h>

int main(void)
{
    int year = 2024;

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
        printf("%d년은 윤년\n", year);
    else
        printf("%d년은 평년\n", year);
    return 0;
}

이전 챕터의 %, ==, &&, ||가 전부 한 번에 쓰이는 문제라서 복습용으로 좋다.
