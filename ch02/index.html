SECTION 01

C 프로그램의 구조

C 프로그램은 함수로 이루어진다. 함수는 "어떤 일을 하는 코드 덩어리"고, 간단한 프로그램은 main 함수 하나로 끝나기도 한다. main은 프로그램의 시작점이라 반드시 있어야 한다. 함수는 7장에서 자세히 배우니 지금은 모양만 외워두자.

C
/* 10과 20을 더하는 프로그램
   (여러 줄 주석) */

int main(void)        // 머리: 함수 이름과 필요한 데이터를 적는 곳
{                     // 몸통 시작
    10 + 20;          // 하고 싶은 일
    return 0;         // 프로그램 종료
}                     // 몸통 끝

함수는 머리(head)와 몸통(body)으로 나뉜다. 머리를 함수 원형이라고도 부른다. 할 일은 { } 안에 적는다.

이 프로그램을 돌려도 화면에는 아무것도 안 나온다. 10과 20을 더하긴 했지만 "그 결과를 어쩌라"는 명령이 없기 때문이다. 결과를 보려면 출력 함수가 필요하다.

주석

형태 범위
/* ~ */ 사이에 있는 모든 내용 (여러 줄 가능)
// 그 줄 끝까지

/* */는 줄 중간에도 끼울 수 있다.

C
10 /* 첫 번째 수 */ + 20 /* 두 번째 수 */;

주석은 전처리 단계에서 지워져서 컴파일러는 보지도 못한다. 사람이 읽으라고 쓰는 거니까 자세히 쓸수록 좋다.

문장 쓰는 규칙

  • 문장 끝은 세미콜론(;). 문장의 마침표라고 생각하면 된다. 빠지면 컴파일러가 다음 줄까지 한 문장으로 읽어서 엉뚱한 줄에 에러를 띄운다.
  • 한 줄에 한 문장씩. 세미콜론으로 구분만 되면 한 줄에 여러 문장, 한 문장을 여러 줄에 쓰는 것도 문법상은 되지만 읽기 힘들다.
  • 들여쓰기는 일정하게. 칸 수는 정해져 있지 않고 VC++은 기본 4칸이다.
SECTION 02

printf: 화면에 출력하기

printf는 print formatted, 정해진 형식에 따라 출력한다는 뜻이다. 읽을 때는 "프린트에프". 기본 기능은 문자열 출력이고, 쓰려면 #include <stdio.h>가 있어야 한다.

C
#include <stdio.h>

int main(void)
{
    printf("Be happy");
    printf("My friend");
    return 0;
}

두 줄로 썼는데 실행하면 Be happyMy friend처럼 한 줄에 붙어서 나온다. 줄 바꿈은 알아서 안 해주기 때문이다. 줄을 바꾸려면 제어 문자를 써야 한다.

참고로 'a'처럼 한 글자는 문자, "apple"처럼 글자가 이어진 건 문자열이다.

SECTION 03

제어 문자

제어 문자는 글자로 찍히는 게 아니라 출력 방식에 영향을 주는 문자고, 백슬래시(\)와 같이 쓴다. 한국 키보드에서는 \ 자리에 ₩가 찍히기도 한다.

제어 문자 이름 하는 일
\n 개행(new line) 다음 줄로 이동
\t 탭 다음 탭 위치로 이동
\r 캐리지 리턴 줄 맨 앞으로 이동
\b 백스페이스 한 칸 왼쪽으로 이동
\a 알럿 경고음(벨소리)
C
printf("Be happy\n");
printf("12345678901234567890\n");
printf("My\tfriend\n");
printf("Goot\bd\tchance\n");
printf("Cow\rW\a\n");

하나씩 따라가보면 이렇다.

  • \n: 출력하고 줄을 바꾼다.
  • \t: 화면을 8칸 단위로 나눠서 각 구역의 첫 칸(1, 9, 17번째 칸…)이 탭 위치다. 커서가 1~8번 칸 어디 있든 \t를 만나면 9번 칸으로 간다. 그래서 열을 맞춰서 출력할 때 좋다.
  • \b: Goot을 찍고 \b로 한 칸 뒤로 가서 d를 찍으면 마지막 t가 d로 덮여서 Good이 된다. 그 뒤 \t로 탭 이동.
  • \r: Cow를 찍고 맨 앞으로 돌아가서 W를 찍으면 C가 W로 덮여서 Wow가 된다. \a는 소리만 낸다.

\b와 \r은 "이미 찍은 글자를 덮어쓴다"는 점이 포인트. 실제 콘솔에서 돌려보면 이해가 빠르다.

SECTION 04

숫자 출력: 변환 문자

printf는 기본적으로 문자열을 출력하는 함수라서 숫자를 찍으려면 변환 문자로 문자열 형태를 알려줘야 한다. 정수는 %d(decimal), 실수는 %lf(long float)를 쓴다.

C
#include <stdio.h>

int main(void)
{
    printf("%d\n", 10);                 // 10
    printf("%lf\n", 3.4);               // 3.400000
    printf("%.1lf\n", 3.45);            // 소수점 첫째 자리까지
    printf("%d + %d = %d\n", 10, 20, 10 + 20);
    return 0;
}

따옴표 안의 %d 자리에 콤마 뒤의 값이 앞에서부터 차례대로 들어간다. 변환 문자 개수와 값 개수는 맞아야 한다. 값 자리에 10 + 20 같은 식을 쓰면 계산한 결과가 찍힌다.

소수점 자릿수와 반올림

%lf는 소수점 아래 6자리까지 찍는다. 자릿수를 바꾸려면 %와 lf 사이에 점과 숫자를 넣는다.

C
printf("%lf\n", 3.4);      // 3.400000
printf("%.1lf\n", 3.45);   // 3.5 (둘째 자리에서 반올림)
printf("%.2lf\n", 3.14159); // 3.14

잘리는 부분은 반올림돼서 나온다. 그리고 유효 숫자가 6자리를 넘는 값을 그냥 %lf로 찍으면 뒷부분이 잘려 보이니까, 자릿수를 충분히 크게 잡아야 한다.

정리: printf 사용법

출력할 것 예 결과
문자열 printf("Be happy!"); Be happy!
제어 문자 printf("Be happy!\n"); Be happy! 후 줄 바꿈
정수 printf("%d", 10); 10
실수 printf("%lf", 3.4); 3.400000
식 printf("%d", 10 + 20); 30
SECTION 05

상수: 바뀌지 않는 데이터

C에서 다루는 데이터는 정수, 실수, 문자, 문자열이다. 그리고 값이 바뀔 수 있는 건 변수, 안 바뀌는 건 상수다. 코드에 직접 적은 값이 상수고, 원주율(3.14)처럼 정해져 있고 바뀌면 안 되는 값에 쓴다.

종류 예 표현 방법
정수 상수 10, -3, 0 0~9, +, -
실수 상수 3.4, -1.5, .5 위 + 소수점
문자 상수 'A', '0' 작은따옴표로 한 글자
문자열 상수 "A", "banana" 큰따옴표로 글자들

'A'와 "A"는 다르다. 글자가 하나여도 큰따옴표로 감싸면 문자열이다. 구분하는 건 따옴표 종류뿐이다.

문자는 %c, 문자열은 %s로 출력한다.

C
printf("%c\n", 'A');            // A
printf("%s\n", "A");            // A
printf("%c와 %s\n", '1', "first");   // 1와 first
SECTION 06

정수 상수와 진법

정수는 10진수, 8진수, 16진수로 쓸 수 있다. 0~15를 비교하면 이렇다.

10진수 0 1 … 7 8 9 10 11 12 13 14 15
8진수 0 1 … 7 10 11 12 13 14 15 16 17
16진수 0 1 … 7 8 9 A B C D E F

8진수는 숫자를 0~7 여덟 개만 쓰니까 8이 되면 자리가 올라가서 10이 된다. 16진수는 0~9에 A~F(10~15)까지 총 16개를 쓴다. 2진수는 길어서 코드에 쓰기엔 불편하다.

10이 10진수인지 8진수인지 코드만 봐서는 모르니까 접두사로 구분한다.

진법 접두사 예 10진수 값
10진수 없음 13 13
8진수 0 (영) 015 13
16진수 0x (영엑스) 0xD 13
C
printf("%d\n", 13);    // 13
printf("%d\n", 015);   // 13
printf("%d\n", 0xD);   // 13

세 개 다 같은 값이라서 결과가 똑같다. 앞에 0을 붙이면 8진수가 된다는 걸 모르고 011을 11이라고 쓰면 9가 나온다.

다른 진법으로 출력하기

10진수 값도 변환 문자로 8진수나 16진수로 찍을 수 있다.

변환 문자 출력
%d 10진수
%o 8진수
%x 16진수(소문자 a~f)
%X 16진수(대문자 A~F)
C
printf("%o\n", 13);    // 15
printf("%x\n", 255);   // ff
printf("%X\n", 255);   // FF
SECTION 07

실수 상수

실수는 소수점 형태와 지수 형태로 쓴다.

  • 소수점 형태: 3.4, -1.6, +10.0. 소수점 앞뒤의 의미 없는 0은 생략 가능해서 .5, 10.도 된다.
  • 지수 형태: 아주 크거나 작은 값을 쓸 때 편하다. 0.0000314는 3.14 × 10⁻⁵인데, C에서는 ×10을 e로 바꿔서 3.14e-5라고 쓴다. e는 대문자 E도 된다.

지수 형태는 같은 값을 여러 방식으로 쓸 수 있다. 31.4e-6, 0.314e-4, 3.14e-5는 모두 같은 값이다. 그중 소수점 앞에 0이 아닌 숫자가 한 자리만 오게 맞춘 걸 정규화 표기법이라 하고, printf가 지수로 찍을 때는 항상 이 형태로 찍는다.

C
printf("%.1lf\n", 1e6);        // 1000000.0  (지수로 써도 기본 출력은 소수점)
printf("%.7lf\n", 3.14e-5);    // 0.0000314
printf("%le\n", 0.0000314);    // 3.140000e-05
printf("%.2le\n", 0.0000314);  // 3.14e-05

코드에 지수로 썼어도 %lf로 찍으면 소수점 형태로 나온다. 지수 형태로 보고 싶으면 %le를 쓰고, .2처럼 소수점 이하 자릿수도 지정할 수 있다. 3.14e-5는 소수점 이하 7자리라서 %lf(6자리)로 찍으면 잘리니 %.7lf로 찍어야 한다.

SECTION 08

컴파일되고 나면 상수는 어떤 모양일까

코드는 사실 텍스트일 뿐이다. 10 + 20;을 입력하면 1, 0, 공백, +, … 이 전부 문자로 저장된다. 컴퓨터 입장에서 +는 "더하라"는 명령이 아니라 그냥 + 글자고, 10도 계산할 수 있는 수가 아니라 글자 두 개다. 컴파일을 거쳐야 연산자는 명령어, 상수는 계산 가능한 값으로 바뀐다. 그래서 컴파일 없이는 실행이 안 된다.

컴퓨터는 모든 걸 비트(bit)로 저장한다. 1비트는 0 또는 1, 8비트가 1바이트다. 1바이트는 2⁸ = 256가지 값을 표현하고, 4바이트(32비트)는 2³² 가지. 크기가 클수록 큰 값을 쓸 수 있지만 메모리와 연산 부담이 커서 무작정 키울 순 없다.

상수 종류 크기 변환 형태
정수 4바이트(32비트) 2진수
실수 8바이트(64비트) IEEE 754의 double 형식
문자 아스키 코드 값(정수와 같은 방식) 2진수

정수와 실수는 같은 숫자여도 다르게 저장된다

10과 10.0은 눈엔 거의 같지만 컴퓨터는 전혀 다른 비트 모양으로 저장한다. 정수는 4바이트에 그냥 2진수로 1010, 실수는 8바이트에 부호·지수·소수 규칙대로 저장한다. 정수가 연산도 제일 빠르고 정확해서 정수로 되는 건 정수 상수를 쓰는 게 좋다.

문자 상수

문자는 아스키 코드 값으로 저장돼서 컴퓨터 안에서는 정수와 똑같이 다뤄진다. 예를 들어 'A'의 아스키 값은 65고, 정수 65와 같은 비트로 저장된다. 아스키 코드는 128개 문자(영문 대소문자, 숫자, 특수문자, 제어 문자)에 번호를 붙여둔 약속이다.

정수 상수 범위

양수는 값을 그대로 2진수로 바꾸고 남는 앞자리를 0으로 채운다. 13은 1101이니까 32비트로는 앞에 0이 28개 붙는다.

n비트로 쓸 수 있는 양의 정수 범위는 0 ~ 2ⁿ−1이다.

비트 수 범위
1비트 0 ~ 1
8비트 0 ~ 255
32비트 0 ~ 4294967295

4294967295보다 큰 정수 상수를 쓰면 컴파일러가 알아서 8바이트로 늘려 처리한다(VC++ 기준). 값이 작아도 8바이트로 만들고 싶으면 뒤에 LL(또는 ll)을 붙인다. Long Long이라는 뜻.

C
13        // 4바이트
13LL       // 8바이트

음수는 2의 보수

음수는 절댓값을 2의 보수로 바꿔 저장한다. 2의 보수는 "비트를 전부 뒤집고(1의 보수) 1을 더한 것"이다. -10을 8비트로 흉내 내면:

  1. 절댓값 10 → 00001010
  2. 비트 뒤집기 → 11110101
  3. 1 더하기 → 11110110 ← 이게 -10

왜 이렇게 하냐면, 부호 처리 없이 양수와 음수를 그냥 더해도 맞는 결과가 나오기 때문이다. 10(00001010)과 -10(11110110)을 더하면 100000000이 되는데, 8비트를 넘어선 맨 앞 올림수는 버려져서 결과가 0이 된다.

실수는 IEEE 754 double 형식

실수는 2진수로 그대로 바꾸면 값이 클수록, 소수점이 길수록 비트가 너무 많이 필요해서 규칙을 따로 정했다. 8바이트(64비트)를 이렇게 나눈다.

구간 비트 수 역할
부호 비트 1 0이면 양수, 1이면 음수
지수부 11 지수 값
소수부 52 소수 값

표현할 수 있는 범위는 대략 ±1.8 × 10³⁰⁸ 정도로 엄청 넓다.

실수에는 오차가 있다

범위는 넓은데 정확도는 한계가 있다. 0.1234567890123456789처럼 유효 숫자가 많으면 정확히 저장이 안 되고 오차가 생긴다. 소수부 비트는 2⁻¹(0.5), 2⁻²(0.25), 2⁻³(0.125), 2⁻⁴(0.0625)… 같은 값들의 합으로만 소수를 만드는데, 예를 들어 0.09는 이 값들의 조합으로 딱 떨어지게 못 만들어서 가장 가까운 값으로 저장된다. 비트가 52개로 늘어도 한계는 있어서 double은 유효 숫자 15자리 정도까지만 믿고 쓰는 게 안전하다.

SECTION 09

출력할 때 알아두면 좋은 것들

글자 자체를 찍고 싶을 때

쓰는 것 찍히는 것
\\ 역슬래시 \
\" 큰따옴표 "
\' 작은따옴표 '
%% 퍼센트 %

%는 제어 문자가 아니라 printf 규칙이라 \%가 아니라 %%다. 은근히 헷갈린다.

C
printf("정답률 80%%\n");
printf("그는 \"안녕\"이라고 했다\n");

폭 맞추기

C
printf("[%5d]\n", 42);     // [   42]  폭 5칸, 오른쪽 정렬
printf("[%-5d]\n", 42);    // [42   ]  왼쪽 정렬
printf("[%05d]\n", 42);    // [00042]  빈칸을 0으로

표처럼 줄을 맞춰 출력할 때 쓸모 있다.

문자는 숫자이기도 하다

문자가 아스키 값으로 저장된다는 건 이런 뜻이다. 같은 값을 %c로 찍으면 문자, %d로 찍으면 숫자.

C
printf("%c\n", 'A');   // A
printf("%d\n", 'A');   // 65
printf("%c\n", 66);    // B

대문자 A는 65, 소문자 a는 97로 차이가 32다. 나중에 대소문자를 바꿀 때 쓸 수 있다.

지정자와 값은 짝이 맞아야 한다

정수를 %lf로 찍거나 개수를 안 맞추면 엉뚱한 값이 나온다.

C
printf("%d + %d = %d\n", 3, 4, 7);   // 3 + 4 = 7
“
ONE-LINE SUMMARY

printf는 %d, %lf, %c, %s 같은 변환 문자 자리에 값을 차례로 끼워 출력하고, 상수는 컴파일되면 정수는 4바이트 2진수, 실수는 8바이트 IEEE 754, 문자는 아스키 값으로 바뀐다.
