상수와 데이터 출력

상수의 네 가지 종류, printf 서식 지정자, 이스케이프 시퀀스, 진법

IN THIS CHAPTER

SECTION 01

상수: 값 자체

코드에 직접 적어놓은 값을 상수라고 한다. 종류는 크게 네 가지.

종류 예 비고
정수 10, -3 소수점 없음
실수 3.14, -0.5 소수점 있음
문자 'A' 작은따옴표, 딱 한 글자
문자열 "Hello" 큰따옴표, 여러 글자

'A'와 "A"는 완전히 다르다. 작은따옴표는 문자 하나, 큰따옴표는 문자열이다. 이거 헷갈려서 에러 나는 경우가 진짜 많다.

SECTION 02

printf로 값 출력하기

문자열만 출력할 때는 그냥 쓰면 되지만, 값을 끼워 넣으려면 서식 지정자를 쓴다.

C
#include <stdio.h>

int main(void)
{
    printf("정수: %d\n", 10);
    printf("실수: %f\n", 3.14);
    printf("문자: %c\n", 'A');
    printf("문자열: %s\n", "Hello");
    return 0;
}
지정자 출력하는 것
%d 정수
%f 실수
%c 문자
%s 문자열

따옴표 안의 %d 자리에 뒤에 적은 값이 순서대로 들어간다고 생각하면 된다. 지정자 개수와 값 개수는 맞춰야 한다. 그리고 종류도 맞아야 해서, 정수를 %f로 찍으면 엉뚱한 값이 나온다.

C
printf("%d + %d = %d\n", 3, 4, 7);   // 3 + 4 = 7
SECTION 03

이스케이프 시퀀스

화면에 그대로 못 찍는 문자를 \와 함께 쓰는 것.

표기 의미
\n 줄 바꿈
\t 탭
\\ 역슬래시 \ 자체
\" 큰따옴표 자체
\' 작은따옴표 자체
%% 퍼센트 % 자체

%는 이스케이프가 아니라 printf 규칙이라 \%가 아니고 %%로 쓴다. 이게 은근히 헷갈린다.

C
printf("이름\t점수\n");
printf("철수\t90\n");
printf("정답률 80%%\n");
printf("그는 \"안녕\"이라고 했다\n");
SECTION 04

출력 모양 다듬기

실수는 그냥 %f를 쓰면 소수점 아래 6자리까지 나온다. 자릿수는 직접 정할 수 있다.

C
printf("%f\n", 3.14);     // 3.140000
printf("%.2f\n", 3.14159); // 3.14 (반올림)
printf("[%5d]\n", 42);     // [   42]  폭 5칸, 오른쪽 정렬
printf("[%-5d]\n", 42);    // [42   ]  왼쪽 정렬
printf("[%05d]\n", 42);    // [00042]  빈칸을 0으로

표 형태로 정렬해서 출력할 때 폭 지정이 꽤 쓸모 있다.

SECTION 05

문자는 사실 숫자다

컴퓨터 안에서 문자는 숫자(아스키 코드)로 저장된다. 그래서 같은 값을 %c로 찍으면 문자, %d로 찍으면 숫자가 나온다.

C
printf("%c\n", 'A');   // A
printf("%d\n", 'A');   // 65
printf("%c\n", 66);    // B

대문자 A는 65, 소문자 a는 97이다. 이 차이가 32라는 건 나중에 대소문자 변환할 때 쓸 수 있다.

SECTION 06

진법 출력

C
printf("%d\n", 17);    // 10진수 17
printf("%o\n", 17);    // 8진수  21
printf("%x\n", 255);   // 16진수 ff
printf("%d\n", 0x1F);  // 16진수로 쓴 상수 -> 31
printf("%d\n", 011);   // 8진수로 쓴 상수 -> 9

코드에서 숫자 앞에 0을 붙이면 8진수, 0x를 붙이면 16진수로 읽는다. 011을 11로 착각하기 쉬우니 앞에 0 붙이는 습관은 조심.

printf는 따옴표 안의 서식 지정자(%d, %f, %c, %s) 자리에 뒤의 값을 순서대로 끼워 넣는 함수이고, 개수와 종류를 맞춰야 한다.
