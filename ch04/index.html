SECTION 01

산술 연산자

연산자 의미 예
+ - * 더하기, 빼기, 곱하기 3 * 4 → 12
/ 나누기 7 / 2 → 3
% 나머지 7 % 2 → 1

C에서 제일 먼저 걸려 넘어지는 부분이 나눗셈이다. 정수끼리 나누면 결과도 정수라서 소수점 아래가 그냥 버려진다.

C
#include <stdio.h>

int main(void)
{
    printf("%d\n", 7 / 2);     // 3
    printf("%f\n", 7 / 2.0);   // 3.500000
    printf("%d\n", 7 % 2);     // 1
    return 0;
}

둘 중 하나라도 실수면 실수로 계산된다. %는 정수에만 쓸 수 있다. 나머지 연산은 홀짝 판별(n % 2), 배수 확인(n % 3 == 0) 같은 데 자주 쓰인다.

SECTION 02

대입 연산자

=는 "같다"가 아니라 "오른쪽 값을 왼쪽에 넣는다"는 뜻이다. 그래서 a = a + 1이 성립한다. 줄여 쓰는 복합 대입도 있다.

C
int a = 10;
a += 3;   // a = a + 3  -> 13
a -= 1;   // a = a - 1  -> 12
a *= 2;   // a = a * 2  -> 24
a /= 5;   // a = a / 5  -> 4  (정수 나눗셈)
a %= 3;   // a = a % 3  -> 1
SECTION 03

증감 연산자

++는 1 증가, --는 1 감소. 변수 앞에 붙이느냐 뒤에 붙이느냐에 따라 값이 쓰이는 시점이 다르다.

C
int a = 5;
int b = a++;   // 먼저 b에 5를 넣고, 그 다음 a가 6
printf("%d %d\n", a, b);   // 6 5

a = 5;
b = ++a;       // 먼저 a가 6이 되고, 그 값을 b에 넣음
printf("%d %d\n", a, b);   // 6 6

a++는 쓰고 나서 증가, ++a는 증가하고 나서 쓴다고 외우면 된다. 단독으로 한 줄에 쓸 때는 둘 다 똑같으니 크게 신경 쓸 필요는 없고, 다른 식 안에 같이 들어갈 때만 조심하면 된다.

SECTION 04

관계 연산자

두 값을 비교해서 참이면 1, 거짓이면 0이 나온다.

연산자 의미
== 같다
!= 다르다
> < 크다, 작다
>= <= 크거나 같다, 작거나 같다
C
printf("%d\n", 3 == 3);   // 1
printf("%d\n", 3 != 3);   // 0
printf("%d\n", 5 >= 7);   // 0

C에는 참/거짓 전용 자료형이 따로 없어서 0은 거짓, 0이 아닌 모든 값은 참으로 취급한다. 이게 뒤의 선택문, 반복문에서 계속 중요하게 쓰인다.

=와 ==를 헷갈리는 실수가 진짜 흔하다. if (a = 3)처럼 쓰면 비교가 아니라 대입이라서 항상 참이 된다. 에러도 안 나서 찾기 어렵다.

SECTION 05

논리 연산자

연산자 의미 예
&& 그리고 (둘 다 참) a > 0 && a < 10
|| 또는 (하나라도 참) a < 0 || a > 10
! 부정 (참↔거짓) !(a == 3)

수학에서 0 < a < 10처럼 쓰는 걸 C에서는 이렇게 써야 한다.

C
int a = 5;
printf("%d\n", a > 0 && a < 10);   // 1

0 < a < 10으로 쓰면 에러는 안 나는데 의도대로 동작하지 않는다.

&&는 앞이 거짓이면 뒤를 아예 계산하지 않고, ||는 앞이 참이면 뒤를 계산하지 않는다(단락 평가). 보통은 모르고 써도 문제없지만, 뒤쪽 식에 ++ 같은 게 들어 있으면 그게 실행이 안 될 수 있다.

SECTION 06

형 변환

서로 다른 자료형이 섞이면 더 큰 쪽으로 맞춰서 계산한다(자동 형 변환). 내가 직접 바꾸고 싶을 때는 앞에 (자료형)을 붙인다.

C
int a = 7, b = 2;
printf("%d\n", a / b);           // 3
printf("%f\n", (double)a / b);   // 3.500000
printf("%f\n", (double)(a / b)); // 3.000000

마지막 줄처럼 괄호 위치가 다르면 결과도 다르다. (double)(a / b)는 이미 정수 나눗셈을 끝낸 뒤에 바꾸는 거라 소용이 없다. 평균 구할 때 이걸 틀리는 경우가 많다.

SECTION 07

연산자 우선순위

곱셈, 나눗셈이 덧셈, 뺄셈보다 먼저고, 대입은 거의 맨 마지막이다. 외우려고 하기보다는 헷갈리면 그냥 괄호를 쳐서 의도를 분명하게 쓰는 편이 낫다.

C
int r = 2 + 3 * 4;     // 14
int s = (2 + 3) * 4;   // 20
SECTION 08

비트 연산자 (간단히)

정수를 2진수 비트 단위로 계산하는 연산자도 있다.

연산자 의미
& 비트 AND
| 비트 OR
^ 비트 XOR
~ 비트 반전
<< >> 왼쪽, 오른쪽으로 비트 밀기
C
printf("%d\n", 6 & 3);    // 110 & 011 = 010 -> 2
printf("%d\n", 6 | 3);    // 110 | 011 = 111 -> 7
printf("%d\n", 1 << 3);   // 1을 왼쪽으로 3칸 -> 8

&&, ||(논리)와 &, |(비트)는 이름이 비슷해서 헷갈리지만 완전히 다른 연산자다.
