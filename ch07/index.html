함수(函數 · 函은 상자 → 값을 넣으면 정해진 일을 하고 결과를 내놓는 상자)는 어떤 기능을 하는 코드 덩어리다. 지금까지 쓴 main도 함수고, printf, scanf도 함수다.

SECTION 01

함수를 왜 만드나

printf, scanf처럼 C 언어가 미리 만들어서 제공하는 함수를 표준 라이브러리 함수(標準 · 기준이 되는 것, library · 도서관 → 미리 만들어 모아 둔 함수 묶음)라고 한다. #include <stdio.h>로 불러온 stdio.h 헤더 파일(header · 머리 → 파일 맨 위에 붙이는 파일)에 들어 있다.

그런데 표준 함수는 정해진 대로만 동작한다. 내가 원하는 기능이 따로 있으면 직접 만들어야 한다. 예를 들어 두 정수의 합을 여러 번 구해야 한다면, 그 기능을 함수로 만들어두고 필요할 때마다 부르기만 하면 된다.

함수를 만들고 쓰는 데 필요한 건 딱 세 가지다.

구분 하는 일 예
함수 정의 함수를 실제로 만든다 (기능 구현) int sum(int x, int y) { return x + y; }
함수 호출 만든 함수를 사용한다 sum(10, 20);
함수 선언 이런 함수를 쓸 거라고 컴파일러에게 미리 알린다 int sum(int x, int y);
SECTION 02

함수 정의: 함수 만들기

정의(定義 · 뜻을 정해서 밝힘 → 함수가 뭘 하는지 실제로 만들어 둠)

함수를 만들기 전에 세 가지만 정하면 된다. 두 정수를 더하는 함수로 생각해 보면:

질문 답 이름
① 기능에 맞는 이름은? 더하기 → sum 함수명
② 일할 때 필요한 데이터는? 더할 정수 2개 매개변수
③ 일이 끝나고 돌려줄 결과는? 정수 (정수 + 정수 = 정수) 반환형

이 세 가지를 한 줄로 적은 게 함수 원형(原形 · 본디 모양, function prototype)이다. 원형 아래에 중괄호를 열고 할 일을 적으면 함수 정의가 끝난다.

C
반환형 함수명(매개변수1, 매개변수2)    // 함수 원형
{
    // 함수가 할 일
    // 결과를 return으로 돌려보냄
}

예제: 두 정수를 더하는 함수

C
#include <stdio.h>

int sum(int x, int y);              // 함수 선언

int main(void)
{
    int a = 10, b = 20;
    int result;

    result = sum(a, b);             // 함수 호출
    printf("result : %d\n", result);

    return 0;
}

int sum(int x, int y)               // 함수 정의
{
    int temp;

    temp = x + y;

    return temp;
}
OUTPUT
result : 30

main 말고 sum이라는 함수가 하나 더 생겼다. 함수 안에 또 함수를 정의할 수는 없어서 sum은 main 바깥에 따로 만든다.

함수 원형 뜯어보기

C
int sum(int x, int y)
  • 함수명 sum: 기능을 짐작할 수 있는 이름으로, 변수 이름처럼 식별자 규칙을 따른다. add도 괜찮다.
  • 매개변수(媒介變數 · 둘 사이를 이어 주는 변수, parameter) int x, int y: 함수가 받을 데이터를 담는 변수. 자료형이 같아도 하나씩 따로 적어야 한다. int x, y라고 쓰면 안 된다.
  • 반환형(返還型 · 돌려줄 값의 자료형) int: 함수가 끝나고 돌려줄 값의 자료형. 두 정수의 합이라 int.

함수 안에서 필요한 변수는 int temp;처럼 안에서 따로 선언해서 쓴다.

return

return(돌려주다)은 함수의 결과를 호출한 곳으로 돌려주고 함수를 끝내는 제어문이다. temp에 합을 저장했다가 return temp;로 돌려줬는데, 사실 temp 없이 바로 돌려줘도 된다.

C
int sum(int x, int y)
{
    return (x + y);    // 계산 결과를 바로 반환
}

함수마다 변수 이름이 같아도 된다

C
int sum(int a, int b)     // main에도 a, b가 있지만 상관없음
{
    int result;           // main에도 result가 있지만 상관없음
    result = a + b;       // 여기서 a, b는 main의 a, b가 아니라 매개변수
    return result;
}

변수는 선언한 중괄호 블록 안에서만 쓸 수 있다. 그래서 main의 a와 sum의 a는 이름만 같고 완전히 다른 칸이다. 매개변수도 마찬가지로 그 함수 안에서만 쓸 수 있다. (자세한 건 13장)

SECTION 03

함수 호출: 함수 쓰기

호출(呼出 · 불러냄). 함수는 만들어두기만 하면 저절로 실행되지 않는다. 이름을 불러줘야 실행된다.

C
result = sum(a, b);    // sum 함수 호출

괄호 안에 넣어 주는 값을 인수(引數 · 끌어다 주는 값, argument)라고 한다. 인수에는 리터럴, 변수, 수식이 다 올 수 있다. 수식을 넣으면 계산된 결과가 인수로 들어간다.

C
sum(30, 40);         // 리터럴(상수) 인수
sum(a, b);           // 변수 인수
sum(a * 2, b / 3);   // 수식 인수 → 계산한 값이 들어감

인수는 매개변수에 순서대로 복사된다

sum(a, b)를 호출하면 a의 값은 x로, b의 값은 y로 순서대로 복사된다. 그리고 main은 잠깐 멈추고 sum 안의 코드가 실행된다.

호출하는 쪽 (인수) 받는 쪽 (매개변수)
a (10) → 복사 → x
b (20) → 복사 → y

인수와 매개변수 헷갈리지 않기: 부를 때 넣어 주는 값이 인수, 함수가 그 값을 받아 담는 변수가 매개변수.

실행 순서

  1. 프로그램은 항상 main부터 시작
  2. main을 위에서부터 실행하다가
  3. sum(a, b)를 만나면 sum으로 넘어감 (인수를 매개변수에 복사)
  4. sum 실행
  5. return temp;로 값을 들고 호출한 자리로 돌아옴
  6. main의 나머지를 이어서 실행
SECTION 04

함수 반환: 결과 돌려받기

반환(返還 · 돌려줌). return temp;를 만나면 temp의 값이 함수를 부른 자리로 돌아온다. result = sum(a, b);라면 sum(a, b) 자리에 30이 돌아오고, 그 값이 result에 대입된다.

반환값은 이름 없는 임시 공간에 잠깐 들어 있다가 사라진다. 그래서 바로 변수에 대입하거나, 수식에 그대로 써야 한다.

C
result = sum(a, b) * 2;

이때 순서는 ① sum(a, b) 호출해서 반환값(30) 받기 → ② 30 × 2 → ③ result에 60 대입. 함수 호출이 가장 먼저다.

SECTION 05

함수 선언: 미리 알려 두기

선언(宣言 · 널리 알림). 컴파일러에게 "이런 모양의 함수를 쓸 거야"라고 미리 알리는 것이다. 만드는 법은 간단하다. 함수 원형 뒤에 세미콜론을 붙여서 main 위에 적는다.

C
int sum(int x, int y);    // 함수 선언
int sum(int, int);        // 매개변수 이름은 생략해도 된다

정의가 있는데 왜 선언이 필요할까

컴파일러는 코드를 위에서 아래로 읽는다. 예제처럼 sum이 main보다 아래 있으면, main에서 sum을 만났을 때 컴파일러는 아직 sum이 뭔지 모른다. 그래서 위에서 미리 알려 줘야 한다.

이유 1. 반환형을 미리 알아야 한다. 컴파일러는 함수를 부른 자리에 반환값이 들어올 공간을 준비한다. 정수를 돌려주면 int 크기, 실수면 double 크기. 그러려면 호출하기 전에 반환형을 알아야 한다.

이유 2. 호출을 제대로 했는지 검사한다. 선언에 매개변수 개수와 자료형이 적혀 있으니, 정수 2개를 받는 sum에 실수를 넣으면 컴파일러가 경고를 띄워 준다.

OUTPUT
warning C4244: '함수': 'double'에서 'int'(으)로 변환하면서 데이터가 손실될 수 있습니다.

선언 없이 쓰는 방법도 있다

sum 정의를 main 위에 두면 정의 안에 원형이 이미 들어 있어서 선언이 필요 없다. 코드 순서를 바꿔도 실행 순서는 그대로다. 프로그램은 어디 적혀 있든 항상 main부터 시작하기 때문이다.

다만 함수가 많아지고 서로 부르는 관계가 복잡해지면 순서 맞추기가 힘들다. 그래서 보통은 main 위에 선언을 전부 모아 두고, 정의는 main 아래에 쓴다. 그러면 어떤 함수들이 있는지 한눈에 보이고 순서 신경 안 쓰고 자유롭게 부를 수 있다.

선언도 정의도 없이 먼저 부르면?

컴파일러는 일단 "반환형이 int인 함수겠지" 하고 넘어가면서 경고를 띄운다.

OUTPUT
warning C4013: 'sum'이(가) 정의되지 않았습니다. extern은 int형을 반환하는 것으로 간주합니다.

진짜 반환형이 int면 우연히 돌아가지만, double 같은 다른 자료형이면 나중에 정의를 만났을 때 에러가 난다. 그러니 선언은 꼭 하자.

SECTION 06

07-1 확인 문제

1. 두 실수의 평균을 구하는 함수의 빈칸 채우기

C
double res;                       // 반환값을 저장할 변수
res = average(1.5, 3.4);          // 함수 호출

double average(double a, double b)    // ← 빈칸: double / double a / double b
{
    double temp;
    temp = a + b;
    return (temp / 2.0);
}
  • 반환형: 평균은 실수라서 double
  • 매개변수: 함수 안에서 a, b를 쓰고 있고 실수 2개를 받으니 double a, double b. double a, b로 쓰면 안 되고 각각 자료형을 붙여야 한다.

2. 용어와 설명 연결

용어 설명
함수 선언 함수 원형을 컴파일러에 알린다
함수 정의 함수 원형을 설계하고 내용을 구현한다
함수 호출 함수에 필요한 값을 주고 함수를 사용한다

3. 187cm를 m로 바꿔 출력하기

cm를 m로 바꿔서 돌려주는 함수를 만들고, 호출해서 출력하는 문제.

C
#include <stdio.h>

double centi_to_meter(double cm);     // 함수 선언

int main(void)
{
    double res;                       // 반환값을 저장할 변수

    res = centi_to_meter(187);        // 함수 호출, 반환값을 res에 저장
    printf("%.2lfm\n", res);          // 1.87m

    return 0;
}

double centi_to_meter(double cm)      // 함수 정의
{
    double meter;                     // 필요한 변수 선언

    meter = cm / 100.0;               // cm를 m로 환산 (cm * 0.01 도 같음)

    return meter;                     // 환산된 값 반환
}
OUTPUT
1.87m

정답과 내 풀이 비교

내 풀이는 함수 안에서 0.01을 곱했다.

C
double centi_to_meter(double cm)
{
    double height;
    height = cm * 0.01;    // 1cm = 0.01m
    return height;
}

정답은 cm / 100.0인데, 100으로 나누는 거나 0.01을 곱하는 거나 같은 계산이라 결과는 똑같이 1.87m가 나온다. 변수 이름(meter, height)도 아무거나 써도 된다.

그 밖에 알아둘 점

  • 함수 안에서는 넘겨받은 값이 들어 있는 매개변수 cm을 써야 한다. main의 변수 res는 main 블록 안에서만 쓸 수 있어서, 함수 안에서 res를 쓰면 에러('res' undeclared)가 난다.
  • centi_to_meter(187)처럼 정수 187을 넣어도, 선언에서 매개변수가 double이라고 알려줬기 때문에 자동으로 187.0으로 바뀌어 들어간다. 선언이 이런 역할도 한다.
  • / 100.0처럼 소수점을 붙이는 습관이 좋다. 지금은 cm이 double이라 / 100으로 해도 되지만, cm이 int였다면 187 / 100은 정수 나눗셈이라 1이 나온다.
  • %.2lf는 소수점 아래 둘째 자리까지 출력한다. 뒤에 붙은 m은 그냥 글자라 1.87m로 찍힌다.
SECTION 07

07-2 여러 가지 함수 유형

07-1에서는 함수 원형이 반환형 함수명(매개변수) 모양이라고 배웠다. 그런데 모든 함수에 반환형과 매개변수가 다 필요한 건 아니다. 함수가 하는 일에 따라 모양이 달라진다.

하는 일 매개변수 반환값 예
키보드로 직접 입력받아서 돌려줌 없음 있음 int get_num(void)
받은 값을 화면에 출력만 함 있음 없음 void print_char(char ch, int count)
늘 같은 내용을 출력만 함 없음 없음 void print_line(void)

없는 자리에는 void(빈, 아무것도 없는)를 적는다.

SECTION 08

매개변수가 없는 함수

키보드로 양수를 입력받아서 돌려주는 함수를 생각해 보자. 값을 함수 안에서 scanf로 직접 받으니까, 호출하는 쪽에서 넘겨줄 게 없다. 이럴 땐 매개변수 자리에 void를 쓴다.

C
#include <stdio.h>

int get_num(void);                  // 함수 선언

int main(void)
{
    int result;

    result = get_num();             // 함수 호출 (인수 없이 괄호만)
    printf("반환값 : %d\n", result);
    return 0;
}

int get_num(void)                   // 매개변수는 없고 반환형만 있다
{
    int num;                        // 키보드 입력값을 저장할 변수

    printf("양수 입력 : ");
    scanf("%d", &num);

    return num;                     // 입력한 값 반환
}
OUTPUT
양수 입력 : 10
반환값 : 10
  • 정의/선언할 때: int get_num(void). 괄호만 써도(int get_num()) 되지만, void를 넣어서 "매개변수 없음"을 확실히 표시하는 게 좋다.
  • 반환형은 있다: 입력받은 값을 돌려줘야 하니까 int와 return num;이 필요하다.
  • 호출할 때: get_num()처럼 괄호만 쓴다. get_num(void)라고 쓰면 안 된다. void는 선언과 정의에서만 쓴다. 괄호까지 빼고 get_num이라고만 쓰면 함수를 부르는 게 아니라 그냥 이름으로 읽혀서 안 된다.

음수가 들어오면 다시 받기 (예외 처리)

양수를 받아야 하는데 사용자가 음수를 넣을 수도 있다. while로 음수인 동안 계속 다시 입력받게 고치면 더 믿을 만한 함수가 된다.

C
int get_num(void)
{
    int num;

    printf("양수 입력 : ");
    scanf("%d", &num);
    while (num < 0)                 // 음수가 들어오면 다시 입력받기
    {
        printf("양수를 입력하세요!\n");
        printf("양수 입력 : ");
        scanf("%d", &num);
    }
    return num;
}

이렇게 사용자가 예상과 다르게 쓸 때를 대비해서 코드를 넣는 걸 예외 처리(例外 · 일반 규칙에서 벗어나는 경우)라고 한다. 한 번 이렇게 만들어 두면 어디서 호출하든 항상 양수를 받을 수 있다.

SECTION 09

반환값이 없는 함수

받은 데이터를 화면에 출력만 하는 함수는 돌려줄 값이 없다. 출력한 것 자체가 할 일이니까. 이럴 땐 반환형 자리에 void를 쓴다.

문자와 숫자를 받아서 그 문자를 숫자만큼 출력하는 함수:

C
#include <stdio.h>

void print_char(char ch, int count);    // 함수 선언

int main(void)
{
    print_char('@', 5);                 // 문자와 숫자를 주고 호출

    return 0;
}

void print_char(char ch, int count)     // 매개변수는 있고 반환형은 없다
{
    int i;

    for (i = 0; i < count; i++)         // count번 반복
    {
        printf("%c", ch);               // 받은 문자 출력
    }

    return;                             // 값 없이 return만 (생략 가능)
}
OUTPUT
@@@@@
  • 매개변수는 문자와 숫자 두 개가 필요하니까 있다: char ch, int count
  • 돌려줄 값이 없으니 반환형은 void
  • return;처럼 값 없이 return만 쓴다. 아예 빼도 된다. 함수 끝까지 실행하면 알아서 호출한 곳으로 돌아간다.

중간에 끝내고 싶을 때도 return

return은 함수 어디서든 쓸 수 있다. 예를 들어 count가 10보다 크면 아무것도 안 하고 바로 끝내고 싶다면:

C
void print_char(char ch, int count)
{
    int i;

    if (count > 10) return;         // 여기서 함수 실행이 끝난다
    for (i = 0; i < count; i++)
    {
        printf("%c", ch);
    }
    return;
}

void 함수에서 주의할 점

  • 반환형이 void인데 return 10;처럼 값을 돌려주려고 하면 경고가 뜬다.
OUTPUT
warning C4098: 'print_char': 'void' 함수에서 값을 반환하고 있습니다.
  • 돌려받는 값이 없으니 수식 안에 쓸 수 없다. print_char('@', 5) + 10은 더할 값이 없어서 안 된다. 호출만 단독 문장으로 쓴다.
SECTION 10

매개변수와 반환값이 모두 없는 함수

늘 똑같은 내용을 출력하는 함수는 받을 것도, 돌려줄 것도 없다. 둘 다 void.

C
#include <stdio.h>

void print_line(void);              // 함수 선언

int main(void)
{
    print_line();                   // 함수 호출
    printf("학번      이름      전공      학점\n");
    print_line();                   // 함수 호출

    return 0;
}

void print_line(void)               // 매개변수도 반환값도 없다
{
    int i;

    for (i = 0; i < 50; i++)        // '-'를 50번 출력
    {
        printf("-");
    }
    printf("\n");
}
OUTPUT
--------------------------------------------------
학번      이름      전공      학점
--------------------------------------------------

print_line은 위의 두 종류를 합친 모양이다. 호출할 때 아무것도 안 넘겨주고(print_line()), return도 없고, 수식 안이 아니라 혼자 한 문장으로 쓴다.

SECTION 11

재귀호출 함수

재귀호출(再歸 · 다시 돌아옴, recursive call)은 함수가 자기 자신을 다시 호출하는 것이다. 지금까지는 main이 sum을 부르는 식으로 다른 함수를 불렀는데, 재귀는 fruit 안에서 fruit를 또 부른다.

멈추는 조건이 없으면

C
void fruit(void)
{
    printf("apple\n");
    fruit();                        // 자기 자신을 다시 호출
}

apple을 찍고 → 다시 fruit() → apple 찍고 → 다시 fruit() … 끝나지 않는다. 그런데 실제로 돌려보면 무한히 찍지 않고 한참 찍다가 강제 종료된다.

함수는 호출될 때마다 메모리를 조금씩 쓴다. 끝나지 않고 계속 호출하면 프로그램 하나가 쓸 수 있는 메모리(스택 메모리, stack · 차곡차곡 쌓인 더미)를 다 써버려서 멈추는 것이다. 이걸 스택 오버플로라고 하고, 컴파일러도 경고를 띄운다.

OUTPUT
warning C4717: 'fruit': 모든 제어 경로에서 재귀적입니다. 함수로 인해 런타임 스택 오버플로가 발생합니다.

메모리가 모자라서 죽는 건 정상 종료가 아니다. 그래서 재귀 함수에는 반드시 멈추는 조건이 있어야 한다.

세 번만 실행되게 만들기

몇 번째 호출인지 기억하려고 매개변수 count를 쓰고, 3번째면 return으로 멈춘다.

C
#include <stdio.h>

void fruit(int count);

int main(void)
{
    fruit(1);                       // 처음 호출이라 1을 준다

    return 0;
}

void fruit(int count)               // 몇 번째 호출인지 count로 받는다
{
    printf("apple\n");
    if (count == 3) return;         // 3번째면 여기서 끝
    fruit(count + 1);               // 아니면 count를 1 늘려서 다시 호출
}
OUTPUT
apple
apple
apple
호출 count 하는 일
fruit(1) (main에서) 1 apple 출력 → 3이 아니니 fruit(2) 호출
fruit(2) 2 apple 출력 → 3이 아니니 fruit(3) 호출
fruit(3) 3 apple 출력 → 3이니 return, 재귀 멈춤

return하면 어디로 돌아갈까

fruit 맨 끝에 printf("jam\n"); 한 줄을 추가해 보자.

C
#include <stdio.h>

void fruit(int count);

int main(void)
{
    fruit(1);

    return 0;
}

void fruit(int count)
{
    printf("apple\n");
    if (count == 3) return;
    fruit(count + 1);
    printf("jam\n");                // 새로 추가한 줄
}
OUTPUT
apple
apple
apple
jam
jam

count == 3에서 return하면 바로 main으로 돌아갈 것 같지만, jam이 두 번 찍혔다. 재귀호출은 바로 직전에 자기를 호출한 곳으로 돌아가기 때문이다.

재귀호출할 때마다 함수의 복사본이 새로 하나씩 생긴다고 생각하면 이해가 쉽다.

  1. main → 1번 복사본 fruit(1): apple 출력, fruit(2) 호출하고 그 자리에서 대기
  2. 2번 복사본 fruit(2): apple 출력, fruit(3) 호출하고 대기
  3. 3번 복사본 fruit(3): apple 출력, count == 3이라 return → 2번 복사본으로 돌아감
  4. 2번 복사본: 기다리던 자리 다음 줄인 jam 출력, 끝 → 1번 복사본으로 돌아감
  5. 1번 복사본: jam 출력, 끝 → main으로 돌아감

3번 복사본은 return에서 끝나서 jam을 못 찍었고, 1번과 2번만 찍어서 두 번이다.

재귀호출과 반복문의 차이

재귀는 겉보기엔 같은 코드를 반복하는 것 같지만, 실제로는 새 함수를 계속 실행하는 것이다. 복잡한 반복을 짧게 쓸 수 있는 경우도 있지만, 코드를 읽기 어렵고 호출할 때마다 메모리를 쓴다. 그래서 반복문으로 할 수 있으면 반복문을 쓰고, 재귀는 꼭 필요할 때만 쓰는 게 좋다.

형태 선언 예 특징

반환값이 없음 void print_char(char ch, int count); return을 안 쓰거나 값 없이 return;만 쓴다. 수식에 못 쓴다
둘 다 없음 void print_line(void); 위 두 가지 특징을 모두 가진다

SECTION 12

07-2 확인 문제

1. 함수 형태에 맞게 호출한 것 고르기 → ④

번호 코드 맞나? 이유
① void func(int, double); → func(1.5, 10); X int, double 순서인데 실수, 정수 순서로 넣었다
② int func(void); → func(void); X 호출할 때는 void를 쓰지 않고 func()로 쓴다
③ void func(void); → func() + 10; X 반환값이 없는 함수는 수식에 쓸 수 없다
④ int func(double); → printf("%d", func(3.4)); O 실수를 넣고, 돌려받은 정수를 %d로 출력. 맞게 썼다

2. 1부터 num까지의 합을 출력하는 sum 함수

sum(10);처럼 호출만 하고 반환값을 받지 않으니 반환형은 void, 정수 하나를 받으니 매개변수는 int num이다. 합은 함수 안에서 계산해서 바로 출력한다.

C
#include <stdio.h>

void sum(int num);                  // 함수 선언

int main(void)
{
    sum(10);                        // 1부터 10까지의 합 출력
    sum(100);                       // 1부터 100까지의 합 출력
    return 0;
}

void sum(int num)                   // 함수 원형
{
    int i, cnt = 0;                 // 반복 변수와 합을 모을 변수

    for (i = 1; i <= num; i++)      // 1부터 num까지
    {
        cnt += i;                   // 합에 더하기
    }
    printf("1부터 %d까지의 합은 %d입니다.\n", num, cnt);
}
OUTPUT
1부터 10까지의 합은 55입니다.
1부터 100까지의 합은 5050입니다.

3. 실행결과 적기 → 9

C
#include <stdio.h>
int func(int n);
int poly(int n);
int main(void)
{
    printf("%d\n", func(-3));
    return 0;
}
int func(int n)
{
    int res;
    res = poly(n);
    if (res >= 0) return res;
    else return -res;
}
int poly(int n)
{
    return ((2 * n * n) + (3 * n));
}
  • func(-3) 호출 → n = -3
  • poly(-3) 호출 → (2 × -3 × -3) + (3 × -3) = 18 + (-9) = 9
  • res = 9, 0 이상이니 return res; → 9
  • printf로 9 출력

func는 결과가 음수면 -res로 부호를 바꿔서 돌려주니까, 결국 절댓값을 돌려주는 함수다. 그리고 함수 안에서 다른 함수(poly)를 부를 수도 있다는 것도 보여 주는 문제다.

SECTION 13

도전 실전 예제: 재귀로 1부터 10까지 합 구하기

1부터 n까지의 합을 구하는 재귀 함수 int rec_func(int n);을 만들어서 1부터 10까지의 합(55)을 출력하는 문제.

재귀로 생각하는 법

반복문이면 1 + 2 + … + 10을 차례로 더하겠지만, 재귀는 문제를 한 단계 작은 같은 문제로 바꿔서 생각한다.

  • 1부터 10까지의 합 = 10 + (1부터 9까지의 합)
  • 1부터 9까지의 합 = 9 + (1부터 8까지의 합)
  • …
  • 1부터 2까지의 합 = 2 + (1부터 1까지의 합)
  • 1부터 1까지의 합 = 1 ← 더 줄일 게 없으니 여기서 멈춤

괄호 안의 "1부터 ○까지의 합"이 바로 rec_func(○)이다. 그래서 규칙은 두 줄이면 끝난다.

  1. 멈추는 조건: n이 1이면 1을 돌려준다.
  2. 나머지: n + rec_func(n - 1)을 돌려준다.
C
#include <stdio.h>

int rec_func(int n);                // 1부터 n까지의 합을 반환하는 함수

int main(void)
{
    printf("%d\n", rec_func(10));   // 55

    return 0;
}

int rec_func(int n)
{
    if (n == 1)                     // ① 멈추는 조건: 1까지의 합은 1
        return 1;

    return n + rec_func(n - 1);     // ② n + (1부터 n-1까지의 합)
}
OUTPUT
55

함수는 rec_func 하나면 된다.

실제로 어떻게 계산되나

내려가기: 답을 모르니까 계속 한 단계 작은 걸 부르면서 대기한다.

호출 돌려줄 값
rec_func(10) 10 + rec_func(9) → 9의 답을 기다림
rec_func(9) 9 + rec_func(8) → 기다림
… …
rec_func(2) 2 + rec_func(1) → 기다림
rec_func(1) 1 (멈추는 조건, 바로 반환)

올라오기: rec_func(1)이 1을 돌려주면, 기다리던 함수들이 차례로 계산을 끝내고 직전에 호출한 곳으로 돌아간다. fruit 예제에서 jam이 거꾸로 찍히던 것과 같은 원리다.

함수 계산 반환
rec_func(2) 2 + 1 3
rec_func(3) 3 + 3 6
rec_func(4) 4 + 6 10
rec_func(5) 5 + 10 15
rec_func(6) 6 + 15 21
rec_func(7) 7 + 21 28
rec_func(8) 8 + 28 36
rec_func(9) 9 + 36 45
rec_func(10) 10 + 45 55 → main으로

내가 막혔던 부분: 함수 안에서 횟수를 세면 안 되는 이유

처음엔 함수 안에 int cnt = 0;을 두고 cnt++ 해서 cnt == 10이면 멈추려고 했다. 그런데 이러면 절대 안 멈춘다. 재귀호출할 때마다 새 복사본이 생기고, 그때마다 cnt도 새로 만들어져서 다시 0부터 시작하기 때문이다. 직접 찍어 보면 cnt가 계속 1이다.

OUTPUT
cnt=1 n=10
cnt=1 n=9
cnt=1 n=8
...

그래서 재귀에서는 "몇 번째인지"를 함수 안의 변수에 기억시키지 않고, fruit(count + 1)이나 rec_func(n - 1)처럼 매개변수로 넘겨주면서 바꿔 나간다. 이번 문제는 n이 10, 9, 8 … 1로 줄어들다가 1에서 멈추니까 따로 셀 필요가 없다.

반복문으로 하면

같은 계산을 반복문으로 쓰면 이렇다. 07-2 확인 문제 2번이랑 같은 방식이다.

C
int rec_func(int n)
{
    int i, total = 0;
    for (i = 1; i <= n; i++)
        total += i;
    return total;
}

결과는 같다. 이번 문제는 재귀를 연습하려는 문제라 재귀로 쓰는 거고, 실제로 이 정도 계산은 반복문이 더 읽기 쉽다.

ONE-LINE SUMMARY
