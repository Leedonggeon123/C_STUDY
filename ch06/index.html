반복문

while, for, do-while과 break, continue, 중첩 반복문

IN THIS CHAPTER

같은 일을 여러 번 시킬 때 쓴다. 반복문 세 가지(while, for, do-while)는 결국 비슷한 일을 하는데 쓰기 좋은 상황이 조금씩 다르다.

SECTION 01

while

조건이 참인 동안 계속 반복한다. 반복하기 전에 조건부터 검사한다.

C
#include <stdio.h>

int main(void)
{
    int i = 1;

    while (i <= 5)
    {
        printf("%d번째\n", i);
        i++;
    }
    return 0;
}

반복문에는 보통 세 가지 요소가 있다. 시작값(i = 1), 계속할 조건(i <= 5), 값 변화(i++). 이 중에서 값 변화를 빼먹으면 조건이 영원히 참이어서 무한 반복이 된다.

SECTION 02

for

위의 세 요소를 한 줄에 모아서 쓴다.

C
for (int i = 1; i <= 5; i++)
{
    printf("%d번째\n", i);
}

for (초기식; 조건식; 증감식) 순서이고, 실행 순서는 이렇다.

  1. 초기식을 한 번 실행
  2. 조건식 검사 → 거짓이면 끝
  3. 중괄호 안 실행
  4. 증감식 실행
  5. 2번으로 돌아감

횟수가 정해져 있으면 for, 몇 번 돌지 모르고 조건만 있으면 while을 주로 쓴다.

합 구하기

C
int sum = 0;

for (int i = 1; i <= 100; i++)
{
    sum += i;
}
printf("1부터 100까지의 합: %d\n", sum);   // 5050

변수 sum을 0으로 초기화해두고 값을 계속 더해가는 패턴이다. 초기화를 안 하면 쓰레기 값에 더하게 되니 주의.

SECTION 03

do ~ while

일단 한 번 실행하고 나서 조건을 검사한다. 조건이 처음부터 거짓이어도 최소 한 번은 실행된다.

C
int n;

do
{
    printf("1 이상의 수를 입력: ");
    scanf("%d", &n);
} while (n < 1);

printf("입력한 수: %d\n", n);

입력을 받고 나서 검증해야 하는 경우에 딱 맞다. 먼저 입력을 받아야 조건을 검사할 수 있으니까. 끝에 ;를 붙이는 걸 잊지 말자.

SECTION 04

break와 continue

키워드 하는 일
break 반복문을 완전히 빠져나감
continue 이번 회차만 건너뛰고 다음 회차로
C
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
        continue;      // 짝수는 건너뜀
    if (i > 7)
        break;         // 7을 넘으면 종료
    printf("%d ", i);
}
// 출력: 1 3 5 7
SECTION 05

무한 루프

조건을 항상 참으로 두고, 안에서 break로 빠져나오게 만드는 방식이다.

C
while (1)
{
    int n;
    printf("숫자(0이면 종료): ");
    scanf("%d", &n);

    if (n == 0)
        break;

    printf("%d의 제곱: %d\n", n, n * n);
}

for (;;)도 같은 의미다. 일부러 만든 무한 루프가 아니라 실수로 생긴 거라면, 프로그램이 멈추지 않으니 Ctrl + C로 강제 종료하면 된다.

SECTION 06

중첩 반복문

반복문 안에 반복문을 넣는다. 바깥이 한 번 돌 때마다 안쪽이 처음부터 끝까지 돈다.

구구단

C
for (int i = 2; i <= 9; i++)
{
    printf("[%d단]\n", i);
    for (int j = 1; j <= 9; j++)
    {
        printf("%d x %d = %2d\n", i, j, i * j);
    }
    printf("\n");
}

별 찍기

C
for (int i = 1; i <= 5; i++)
{
    for (int j = 1; j <= i; j++)
    {
        printf("*");
    }
    printf("\n");
}
OUTPUT
*
**
***
****
*****

바깥 반복(i)은 줄 수, 안쪽 반복(j)은 그 줄에서 몇 개를 찍을지를 담당한다고 생각하면 이해가 쉽다. 줄이 바뀔 때만 \n을 출력하니까 printf("\n")은 안쪽 반복문 바깥에 있어야 한다.

SECTION 07

반복문에서 자주 하는 실수

  • for (...);처럼 뒤에 세미콜론을 붙임. 반복문 내용이 빈 문장이 되어버려서 안의 코드는 반복 끝나고 딱 한 번만 실행됨
  • 증감식을 빼먹어서 무한 루프
  • <=와 < 혼동. i <= 5는 5번, i < 5는 4번 도는데(1부터 시작할 때), 하나 차이로 틀리는 오류가 의외로 흔함
  • 합을 구하는 변수를 초기화하지 않음
  • 중첩 반복문에서 안쪽과 바깥쪽에 같은 변수 i를 써서 꼬임
