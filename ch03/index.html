SECTION 01

변수: 값을 담아두는 이름 붙은 칸

상수는 값이 고정이지만, 변수는 값을 바꿔가며 저장할 수 있다. 쓰려면 먼저 어떤 종류의 값을 담을지 정해서 선언해야 한다.

C
#include <stdio.h>

int main(void)
{
    int age;        // 선언
    age = 20;       // 값 넣기
    int year = 2026; // 선언 + 초기화
    printf("%d %d\n", age, year);
    return 0;
}

선언만 하고 값을 안 넣으면 그 칸에는 이전에 있던 아무 값이나 들어 있다(쓰레기 값). 그래서 선언할 때 바로 초기화하는 습관이 좋다.

식별자와 예약어

변수나 함수처럼 프로그래머가 짓는 이름을 식별자라고 한다. 규칙은 이렇다.

  • 영문, 숫자, _만 사용 가능
  • 숫자로 시작할 수 없음 (1st는 안 되고 first는 됨)
  • 대소문자 구분 (age와 Age는 다른 변수)
  • 예약어는 이름으로 못 씀

예약어(키워드)는 int, return, if, while처럼 C 언어가 이미 자기 용도로 정해둔 단어다. 컴파일러가 이걸 보면 "문법의 일부"로 읽기 때문에 변수 이름으로 쓸 수 없다. 에디터에서 색이 다르게 칠해지면 예약어라는 신호.

SECTION 02

자료형

담는 값의 종류와 크기에 따라 자료형이 나뉜다.

자료형 담는 값 크기(보통)
char 문자 1개 (작은 정수) 1바이트
short 작은 정수 2바이트
int 정수 4바이트
long long 아주 큰 정수 8바이트
float 실수 4바이트
double 실수(더 정밀) 8바이트

unsigned: 음수를 포기하고 범위를 두 배로

정수 자료형 앞에 unsigned를 붙이면 음수 없이 0 이상만 담는다. 부호를 표시하던 비트까지 값을 담는 데 쓰니까 최댓값이 거의 두 배가 된다.

C
unsigned int a = 4000000000;   // int로는 못 담는 값
printf("%u\n", a);             // unsigned는 %u로 출력

int는 약 -21억 ~ +21억, unsigned int는 0 ~ 약 42억(4294967295). 나이나 개수처럼 음수가 될 일이 없는 값에 쓴다. 대신 음수를 넣으면 이상한 큰 값이 되니 조심.

크기는 환경에 따라 조금 다를 수 있어서, 직접 확인하고 싶으면 sizeof를 쓴다.

C
printf("%zu\n", sizeof(int));     // 4
printf("%zu\n", sizeof(double));  // 8
printf("%zu\n", sizeof(char));    // 1

실수는 double을 기본으로 쓰는 편이 정확도 면에서 낫다. float은 소수점 7자리쯤부터 오차가 나온다.

범위를 넘으면 (오버플로)

int는 약 -21억 ~ +21억까지만 담는다. 넘으면 에러 없이 이상한 값이 된다.

C
int a = 2147483647;   // int의 최댓값
a = a + 1;
printf("%d\n", a);    // 음수가 나옴

큰 수를 다룰 때는 long long을 쓰고, 출력은 %lld로 한다.

SECTION 03

문자열 저장: char 배열

문자 하나는 char에 담지만, 문자열은 char를 여러 개 이어 붙인 배열에 담는다. 배열은 같은 자료형 칸을 나란히 만든 것이다.

C
char name[20] = "Hong";
printf("%s\n", name);   // Hong

name[20]은 char 20칸이라는 뜻이다. 문자열 끝에는 글자가 아닌 "끝났다"는 표시(\0, 널 문자)가 자동으로 하나 들어가서, 글자 수보다 최소 1칸은 더 크게 잡아야 한다. Hong은 4글자지만 5칸이 필요하다.

배열에는 =로 문자열을 나중에 대입할 수 없다. 선언할 때 초기화는 되는데, 이미 만든 배열에 name = "Kim";처럼 쓰면 에러다. 값을 바꾸려면 문자열 복사 함수를 써야 하고 나중에 배운다.

SECTION 04

데이터 입력: scanf

키보드로 값을 받아서 변수에 넣는다. 변수 앞의 &가 핵심이다.

C
#include <stdio.h>

int main(void)
{
    int age;
    printf("나이를 입력하세요: ");
    scanf("%d", &age);
    printf("내년에는 %d살\n", age + 1);
    return 0;
}

&는 "이 변수가 있는 위치"를 뜻한다. scanf가 입력받은 값을 그 위치에 넣어주기 때문에 필요한 거고, 빼먹으면 프로그램이 죽는다. printf에는 &를 안 붙이는데 scanf에만 붙인다는 점이 헷갈린다.

입력 지정자는 자료형마다 다르다

자료형 scanf printf
int %d %d
float %f %f
double %lf %lf
char %c %c

double은 %lf(소문자 L)로 받고 %lf로 출력한다. printf에서는 %f로 써도 똑같이 나오지만, scanf에서는 반드시 %lf를 써야 한다. %f로 받으면 값이 엉망이 된다. 이 노트는 책처럼 printf도 %lf로 통일했다.

여러 개를 한 번에 받을 수도 있다.

C
int a, b;
scanf("%d %d", &a, &b);
printf("합: %d\n", a + b);

문자 입력할 때 주의

%c는 공백이나 엔터도 문자로 읽어버린다. 숫자를 받고 바로 문자를 받으면 앞에 남은 엔터를 읽고 넘어가는 문제가 생긴다. 서식 앞에 공백을 하나 넣으면 해결된다.

C
int n;
char c;
scanf("%d", &n);
scanf(" %c", &c);   // %c 앞의 공백이 남은 엔터를 건너뜀

문자열 입력

문자열은 %s로 받고, 배열 이름 앞에는 &를 붙이지 않는다. 배열 이름이 이미 "그 배열이 있는 위치"를 뜻하기 때문이다.

C
char name[20];
scanf("%s", name);
printf("안녕, %s\n", name);

%s는 공백이나 엔터를 만나면 거기서 입력이 끝난다. 그래서 "Hong Gil Dong"을 입력해도 Hong만 들어온다. 그리고 배열 크기보다 길게 입력하면 옆 메모리를 덮어써서 프로그램이 죽을 수 있다.

입력이 비정상 종료되는 경우

  • & 빼먹기: scanf("%d", age);처럼 쓰면 age 안의 쓰레기 값을 위치로 착각하고 거기에 쓰려다 프로그램이 죽는다.
  • 지정자와 자료형 불일치: double 변수에 %d로 받으면 값이 엉망이 된다.
  • 지정자 개수보다 변수가 적을 때: scanf("%d %d", &a);는 두 번째 값을 쓸 곳이 없어 문제가 생긴다.

컴파일은 되는데 실행하자마자 멈춘다면 scanf 줄의 &부터 확인하자.

Visual Studio를 쓸 때

scanf를 쓰면 보안 경고가 에러로 나오는 경우가 있다. 파일 맨 위에 아래 한 줄을 넣으면 된다.

C
#define _CRT_SECURE_NO_WARNINGS

const: 바뀌면 안 되는 값

C
const double PI = 3.14159;

const를 붙인 변수는 값을 바꾸려 하면 컴파일 에러가 난다. 원주율처럼 고정 값은 이름을 붙여두는 게 코드 읽기에도 좋다.
